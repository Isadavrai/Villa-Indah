## Что ещё нужно для полноценного приёма заявок

- Реквизиты оператора/стороны договора, страна регистрации, контакт и юридический адрес.
- Политика хранения: как долго хранится переписка и кто имеет доступ; условия передачи данных отелю.
- Реальные условия предоплаты, отмены, возвратов, обязательные сборы.
- Подтверждение прав на предоставленные фотографии, логотип и анимации.
- Выбранный обработчик заявок и его условия обработки данных. Проверить реальную доставку только после подключения с разрешённым тестовым адресом. Текущая форма отключена, ничего не отправляет.
- CSP сейчас запрещает исходящие запросы формы на сторонние сервисы. При подключении добавить только подтверждённый endpoint в connect-src; серверная валидация/антиспам обязательны.

## Домен: бюджетный запуск

Хостинг GitHub Pages и HTTPS бесплатны. Домен оплачивается ежегодно. Ориентир для обычного .com — $10–20/год, не котировка: проверить конечную цену регистрации, продления и налоги у регистратора. Доступность villaindahbali.com и stayvillaindah.com не подтверждена: публичный RDAP из среды заблокирован прокси (403).

1. Проверить имена в Cloudflare Registrar или другом регистраторе с прозрачной ценой продления. Купить на свой аккаунт, включить 2FA, автопродление и приватность WHOIS, где доступна. Платные SSL, конструктор, почтовый тариф и дополнительные защиты для этого сайта не нужны.
2. После покупки сообщить только домен и регистратора. Не передавать пароль, платёжные данные и recovery codes. Нужный доступ — через штатную интеграцию или минимальные настройки DNS.
3. В репозитории Settings → Pages → Custom domain указать домен; добавить файл CNAME с тем же именем. Это делается только после покупки и настройки, сейчас CNAME не добавлен.
4. Для корневого домена DNS A: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153. Для www CNAME: isadavrai.github.io. Не указывать /Villa-Indah в DNS. При Cloudflare начать с DNS only. Перед применением сверить с актуальной документацией GitHub Pages.
5. Сначала подтвердить владение доменом через Settings → Pages профиля GitHub и TXT, выданный GitHub. Не придумывать значение TXT.
6. Дождаться проверки DNS/сертификата в Pages, включить Enforce HTTPS. Обновить абсолютную og:image и canonical после выбора основного домена. Проверить HTTPS, оба имени, фотографии, формы и Google-карту.

Не обещать точное время DNS или сертификата. Домены и DNS сейчас не изменены, покупок нет.
