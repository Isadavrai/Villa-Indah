# Villa Indah Telegram Media Library

This folder contains approved branded collages for community advertisements.

## Upload once
Upload the generated `Villa_Indah_Telegram_FULL_20_Collages.zip` file to this folder via GitHub's **Add file → Upload files** and rename it to `media-pack.zip` before committing. GitHub Actions workflow `Install Telegram Media Pack` then extracts the 20 images into `assets/telegram/ru/` and `assets/telegram/en/`, and removes the temporary ZIP.

Only the original user-supplied photo collages should be used as sources. The branded versions use a deterministic header and footer; they do not replace or redraw the photographs.

The Telegram publisher will use media links:
`https://raw.githubusercontent.com/Isadavrai/Villa-Indah/main/assets/telegram/ru/private_pool.jpg`
`https://raw.githubusercontent.com/Isadavrai/Villa-Indah/main/assets/telegram/en/private_pool.jpg`

All marketing materials must follow community rules. The Telegram bot remains in private preview mode until permissions are verified.
